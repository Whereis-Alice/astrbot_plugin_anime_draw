# 二次元抽抽乐

在 QQ 群里抽角色、收集、许愿和交换的 AstrBot 插件。支持 QQ 官方机器人和 OneBot v11（如 NapCat）。原「二次元笑传之抽抽Bot」的游戏指令和角色 ID 可以继续使用。

## 安装

1. 打开 AstrBot 仪表盘，在「插件管理」选择从链接安装。
2. 输入 [本项目的 GitHub 仓库](https://github.com/Whereis-Alice/astrbot_plugin_anime_draw)。
3. 在 QQ 群里发送 `@机器人 菜单` 开始。默认每人每小时可抽 5 次，结婚冷却 60 分钟，后宫上限 20 人。

群聊游戏需要 AstrBot 4.16 至 4.x。内置「数据管理」页面需要 AstrBot 4.29.4 或更新的 4.x 版本。

同一个机器人在同一个群里应只启用一个版本的游戏。新旧插件各自保存数据，但共用原指令。在旧服同时安装两版做迁移时，可先关闭新版配置中的「启用群聊游戏」，继续用旧插件玩。

## 群聊指令

下表省略了 `@机器人`。使用自己的唤醒前缀也可以，具体由 AstrBot 的会话配置决定。

| 指令 | 用途 |
| --- | --- |
| `菜单` / `帮助` | 查看指令和常用入口。 |
| `抽卡` / `ck` | 从群卡池抽角色，查看角色出处和本小时剩余次数。 |
| `结婚 <短码>` | 在结果有效期内收集角色，群友也可以参与。 |
| `我的后宫 [页码]` | 查看收藏、最爱、羁绊加成和总人气。 |
| `最爱 <角色ID>` / `离婚 <角色ID>` | 标记最爱或解除和角色的婚姻。 |
| `搜索 <角色名>` / `查询 <角色ID> [图片序号]` | 命中单个角色时显示图片和详情。多个结果时可在 QQ 官方机器人卡面点击「查看」按钮。 |
| `许愿 <角色名或ID>` / `愿望单` / `删除许愿 <角色名或ID>` | 管理许愿。支持别名及唯一匹配的部分名称，多个候选时可用 ID 指定。 |
| `交换 <我的角色ID> <对方角色ID>` | 发起交换。被邀请者可发送 `交换 接受 <短码>`。 |
| `群排行` | 查看本群收藏总人气前十名。 |
| `添加图片 <角色ID>` / `清除图片 <角色ID>` | 收藏了该角色的玩家可以随 QQ 图片附件上传，或清除其自定义图片。OneBot 支持回复图片。清除图片也可由管理员执行。 |

同一玩家对一个角色的许愿只计一次。同群不同玩家的许愿会叠加该角色的人气，每位许愿者乘以 1.1。每次抽卡有 0.3% 的机会从自己的愿望单随机抽一个角色，其余按常规卡池抽取。

### QQ 官方机器人与 OneBot

- **QQ 官方机器人**的抽卡结果可点「结婚」「再抽一次」或「我的后宫」。每张卡的结婚按钮和短码独立计时，有效期为 3 分钟。按钮不可用时，结果会显示手输短码。交换邀请可点「接受交换」，有效期为 120 秒。菜单还提供抽卡、后宫、愿望单等快捷入口。
- **OneBot** 可以给抽卡结果贴表情或回复结果「结婚」，也可以输入短码。被邀请者给交换邀请贴表情即可接受。短码有效期为 45 秒。
- QQ 官方群聊里的贴表情事件未交给 AstrBot 插件处理。请使用快捷按钮或短码。Markdown 和按钮需要 QQ 开放平台授予权限，接口拒绝时会回退，手动指令仍会显示在消息里。
- 「QQ 官方机器人图文发送方式」默认是「卡池外链优先」，有 HTTPS 卡池原图时直接嵌入同一条 Markdown。没有外链的图片会尝试上传到 QQ 官方素材库。也可选择「QQ 官方素材优先」，先复用或上传 QQ 素材，额度不足时使用可用的卡池外链。Markdown 卡面按比例限制在 240 × 200 像素内，外链图保留原图清晰度。
- 准备上传 QQ 官方素材时，如果机器人已有 95 张有效图片，插件会清理自己上传超过 1 分钟的素材。QQ 返回额度已满时也会尝试清理，释放名额后重试一次。已发送的消息仍可显示 QQ 保存的图片副本。如果可清理的素材不足，会继续使用卡池外链或普通图文。
- 插件配置里的「QQ 官方机器人快捷按钮」默认开启。关闭后仍可使用 Markdown、图片和手动指令。
- 可以关闭「QQ 官方机器人 Markdown」来使用普通图文。Markdown 接口拒绝时也会回退到普通图文和手动指令。

### 管理员指令

- `重置抽卡次数` 重置当前群所有玩家的每小时抽卡次数。仅管理员可用。
- 群管理员可用 `系统设置` 查看可改参数，也可用 `清理后宫 <玩家ID>` 或 `强制离婚 <角色ID>`。抽卡时段按北京时间，支持跨午夜。
- 群主或超管可用 `刷新 <玩家ID>` 重置抽卡次数和结婚冷却。`终极轮回 确认` 会批量清除当前群的婚姻，保留每名玩家的最爱。
- QQ 官方机器人群里可使用 AstrBot 管理员权限，或在插件配置里添加超管。OneBot 玩家的 ID 是 QQ 号，官方机器人的玩家 ID 可在「数据管理」里查看。

## 数据管理

在 AstrBot 仪表盘打开「插件管理 → 二次元抽抽乐 → 数据管理」。可以按群查看玩家收藏、最爱、愿望单和冷却，重置抽卡及结婚冷却，也可以查看和处理旧档。新群在发送 `菜单` 或 `抽卡` 后出现在页面里。

## 从原插件迁移

QQ 官方群消息里的群和玩家以 OpenID 表示，通常不带昵称。旧群号和旧 QQ 号无法据此直接转换。迁移分两步，管理员先确定哪个群对哪个群，再让玩家认领或请管理员核验身份。

### 1. 旧服采集并导出

1. 在旧 OneBot 实例安装新版，启用「开启旧服采集和发码」，关闭新版的「启用群聊游戏」。
2. AstrBot 管理员在旧群发送 `抽抽乐迁移采集 全部`，一次导入旧插件记录并抓取能取得的 QQ 昵称和群名片。只采集当前群可以省略 `全部`。
3. 在 AstrBot 数据目录下找到 `plugin_data/astrbot_plugin_anime_draw/migration.zip`，通过私密渠道复制到新服的同一路径。迁移包含群成员资料，应当私下保存。

### 2. 新服导入并关联群聊

1. 在新服启用「开启新服旧档认领」。AstrBot 管理员在新群发送 `抽抽乐导入迁移`。
2. 在「数据管理 → 旧档迁移」里为新群选择对应的旧群。角色收藏、最爱、愿望单、冷却、排名和可读的自定义图片均可迁移。等待认领的角色原归属会保留，新服已有归属的数据优先。
3. 关联群聊后，玩家首次使用 `抽卡` 或 `ck` 时会尝试找回旧档。需要验证身份时，机器人会提示使用认领码。请用旧 QQ 账号私聊旧机器人 `抽抽乐迁移码 <旧群号>`，再到对应的新群发送 `抽抽乐认领 <迁移码>`。每个旧账号只可关联一次。若无法私聊旧机器人，管理员可以在玩家于新群互动后，通过「数据管理」核验并人工关联。
4. 可在新服启用「允许首次抽卡按同名自动认领」。插件先使用 QQ 官方消息提供的昵称，缺失时使用同一机器人先前收到的昵称。只有与旧 QQ 昵称或群名片唯一匹配时才会自动恢复。重名或缺少匹配资料时会提示使用认领码或人工核验。如果先前缺少昵称，收到昵称后的首次抽卡会再尝试。本项默认关闭。

认领码在旧服采集存档时随迁移包准备，有效期 30 天。玩家可在复制迁移包后领取。旧服有新增旧档或认领码到期时，可重新采集、复制并导入。

## 角色与作品来源

卡池沿用原插件的 15,783 个角色及其 ID。已通过 Bangumi 角色与条目的关联记录为其中 15,702 个角色建立离线作品索引。查询时最多显示三部关联作品，角色可能同时出现在原作、改编和续作中。索引缺失时，`查询` 可以用已核验的 Bangumi 角色 ID 在线补查。网络不可用时仍可查询角色卡。
